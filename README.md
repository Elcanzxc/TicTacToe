# Cyber Tic-Tac-Toe (Крестики-Нолики) — Production Desktop Game

Премиальная настольная игра «Крестики-Нолики» для Windows с поддержкой двух языков (Русский и English), двух тем оформления и двух режимов механики правил.

---

## ✨ Возможности и функционал

1. **Многоязычность (RU ⇄ EN)**:
   - Полная локализация на **Русский** и **English**.
   - Мгновенное переключение языка в 1 клик прямо в заголовке окна (кнопка `RU` / `EN` с иконкой глобуса) или через окно настроек.

2. **Два режима игровой механики**:
   - **Динамический / Бесконечный (3 фишки, Infinity):** У каждого игрока на доске может быть максимум 3 символа. 4-й ход удаляет старейшую фишку (с настраиваемым предупреждением «Исчезнет»). **Ничьих в этом режиме не бывает!**
   - **Классический (9 клеток):** Стандартные правила игры до заполнения поля.

3. **Две темы оформления (Dark ⇄ Light)**:
   - **Cyber Dark:** Глубокий обсидиановый фон (`#0b0d13`), неоновый циановый (`#00f0ff`) и неоновый розовый (`#ff0055`).
   - **Holo Light:** Премиальное морозное белое стекло с контрастными неоновыми акцентами.
   - Быстрое переключение кнопкой ☀️ / 🌙 в Title Bar.

4. **Интеллектуальные функции**:
   - **Подсказка (Hint 💡):** Математический расчет лучшего хода на базе алгоритма Minimax с золотистой подсветкой рекомендованной клетки.
   - **История ходов (History 📜):** Детальный протокол всех ходов партии с шахматными координатами (`A1`...`C3`), отметками исчезнувших фишек и таймштампами.
   - **Настройка скрытия подсказки исчезающей фишки:** Включение хардкорного режима тренировки памяти (Memory Mode).

5. **Оппонент**:
   - Локальный 1 vs 1 (PvP на одном ПК с кастомизацией имён).
   - Человек против AI (Casual, Medium, Master) с органичной задержкой размышлений 300–480 мс.

6. **Аудио синтезатор**:
   - Нативный Web Audio API без внешних файлов: звуки ходов X/O, звук растворения фишки, победный аккорд, перезвон подсказки, тактильный клик.

---

## 🚀 Команды

```bash
# Запуск в режиме разработки:
npm run dev

# Запуск автоматических тестов:
npm test

# Сборка продакшен-бандла:
npm run build

# Упаковка в Windows .exe инсталлятор (NSIS + Portable):
npm run dist
```
